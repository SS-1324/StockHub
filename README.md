# StockHub

## 프로젝트 목적과 주요 기능

주식 초보자를 위한 커뮤니티 + 모의투자 서비스. 실제 자금이 오가는 서비스가 아니라, 여러 "가상 증권사"에 계좌를 만들어 모의로 매매하고, 그 경험을 커뮤니티·랭킹·용어사전과 함께 나누는 걸 목표로 하는 세미 프로젝트다.

| 기능 | 설명 |
|---|---|
| 홈 | 커뮤니티 최신글 · 투자 랭킹 상위 5명 · 용어사전 랜덤 카드를 한 화면에 미리보기 |
| 커뮤니티 | 자유/종목토론/정보공유/반성일지 4개 카테고리 게시판, 댓글·좋아요·북마크 |
| 종목 라운지 | TradingView 위젯 차트 + 종목별 실시간 채팅(WebSocket) + "살까?팔까?" 실시간 투표 + 해외 종목 검색 |
| 랭킹 | 회원 투자 수익률/수익금 기준 랭킹보드(금·은·동 강조) |
| 용어사전 | 카테고리 6종 주식 용어 사전, 검색/자동완성 |
| 가상 증권사 API | 여러 가상 증권사(수수료 상이)에 계좌 개설/연동, 매수·매도 체결, 거래이력 관리 |
| 내 금융거래 | 여러 증권사에 흩어진 보유 주식·금융상품·현금을 한 화면에 모은 통합 자산 대시보드, 투자 목표 설정 |
| 내 정보 | 내가 쓴 글/댓글/북마크, 팔로워·팔로잉, 문의 내역 |
| 관리자 | 회원 상태·권한 관리, 게시글/댓글 노출 관리, 문의 답변, 용어사전 관리 |

각 기능의 상세 설명은 아래 "페이지별 기능 상세"를 참고.

## 사용 기술

- **Backend**: Spring Boot 4, MyBatis, Spring Security(현재는 인증 없이 전체 허용 상태), Spring WebSocket(STOMP)
- **View**: JSP + JSTL (서버사이드 렌더링)
- **DB**: MySQL (MyBatis 매퍼 XML 기반)
- **외부 연동**: TradingView Advanced Chart 위젯(종목 라운지 차트 렌더링, 별도 API 키 불필요)
- **빌드**: Maven (Maven Wrapper 포함)

## 실행에 필요한 Java·MySQL 버전

| 항목 | 버전 |
|---|---|
| Java | 17 (`pom.xml`의 `java.version`) |
| MySQL | 8.0 이상 권장 (JSON/윈도우 함수 등 사용, `mysql-connector-j` 9.7.0으로 연결) |
| Maven | 별도 설치 불필요 — 저장소에 포함된 `./mvnw`(macOS/Linux) / `mvnw.cmd`(Windows) 사용 |

## DB 생성과 SQL 실행 순서

1. MySQL에 `stockhub`라는 이름의 데이터베이스를 먼저 생성한다.
   ```sql
   CREATE DATABASE stockhub CHARACTER SET utf8mb4;
   ```
2. `sql/StockHub_data.sql`을 실행한다. 테이블 생성(`CREATE TABLE IF NOT EXISTS`)과 컬럼 추가(`ALTER TABLE ... ADD COLUMN`, 이미 있으면 건너뜀)가 모두 조건부(멱등)로 작성돼 있어, 이미 스키마가 있는 DB에 다시 실행해도 안전하다. 회원 계정 데이터는 포함돼 있지 않고(직접 회원가입으로 생성), 용어사전·종목·가상증권사·금융상품 등 참조 데이터가 시딩된다.
3. `sql/migrations/` 폴더에 있는 파일들을 **파일명(날짜) 오름차순으로** 순서대로 실행한다. `StockHub_data.sql` 이후에 추가된 스키마 변경분이 여기 쌓인다(현재 `20260811_community_category_migration.sql` 1건).
4. (선택) 계좌 연동 기능을 테스트하려면 `com.kh.demo.tools.DemoDataGenerator`의 `main()`을 IDE에서 직접 실행해 1년치 거래 이력이 있는 데모 계좌를 채운다 — 아래 "테스트 계정" 참고.

컬럼이 없다는 에러가 나면 코드 문제이기 전에 이 순서대로 SQL이 최신까지 반영됐는지부터 의심할 것 — 이 프로젝트는 팀 공용 DB를 여러 명이 같이 쓰는 구조라 스키마가 일시적으로 어긋나 있을 수 있다.

## 필수 환경변수

`.idea` 폴더는 git에 포함되지 않으므로, IntelliJ Run Configuration에 넣은 환경변수는 로컬에만 남는다. 각자 Run/Debug Configurations → Environment variables에 설정할 것.

| 환경변수 | 필수 여부 | 설명 |
|---|---|---|
| `DB_USERNAME` | 선택 | DB 계정. 설정 안 하면 기본값(`stockhub_team`) 사용 |
| `DB_PASSWORD` | 선택 | DB 비밀번호. 설정 안 하면 기본값 사용 |

둘 다 기본값이 `application.properties`에 들어있어 로컬 DB 계정이 기본값과 같다면 별도 설정 없이도 실행된다(단, 이 기본값 자체가 코드에 평문으로 남아있다는 문제는 "알려진 제한사항" 참고). 현재 외부 유료/인증 API는 쓰지 않으므로 그 외 필수 환경변수는 없다.

## 빌드와 실행 방법

```bash
# 1. 의존성 설치 + 빌드
./mvnw clean install

# 2. 실행 (내장 톰캣, 기본 포트 8080)
./mvnw spring-boot:run
```

실행 후 `http://localhost:8080` 접속. DB(`spring.datasource.url` 기본값 `192.168.10.18:3306/stockhub`)에 접속 가능한 네트워크에 있어야 하며, 다른 네트워크라면 로컬에 별도로 세운 MySQL을 가리키도록 `spring.datasource.url` 또는 환경변수를 조정해야 한다.

## 테스트 계정

이 프로젝트는 회원 데이터를 SQL로 미리 심어두지 않는다 — 회원가입 화면에서 직접 계정을 만들어야 한다.

- **일반 회원**: `/member/join`에서 새로 가입
- **관리자 계정**: 회원가입 후 DB에서 직접 권한을 올려야 한다(가입 시점엔 앱을 통해 ADMIN으로 만들 방법이 없음 — 최초 관리자는 수동 승격이 필요).
  ```sql
  UPDATE member SET member_role = 'ADMIN' WHERE member_id = '가입한_아이디';
  ```
- **계좌 연동 테스트용 데모 계좌** (`docs/demo-accounts.md`): `DemoDataGenerator`로 미리 만들어 둔, 아직 아무 회원과도 연동되지 않은 계좌 9개. 회원가입 후 마이페이지에서 계좌 연동 시 아래 예금주명·계좌번호를 입력하면 1년치 거래 이력이 있는 계좌를 그대로 가져올 수 있다.

  | 증권사 | 예금주명 | 계좌번호 |
  |---|---|---|
  | 스톡증권 | 오지훈 | 110-222-000001 |
  | 허브증권 | 임다은 | 102683300000001 |
  | KH투자증권 | 문가영 | 789456120001 |

  (전체 9개 목록은 `docs/demo-accounts.md` 참고. 한 계좌는 한 번 연동되면 재사용 불가 — 다시 테스트하려면 `DemoDataGenerator`를 재실행하거나 `account_link`에서 해당 행을 지울 것)

## 알려진 제한사항

- **매수/매도 버튼 없음**: `brokerage` 패키지에 체결 API(`POST /api/accounts/{id}/trades`)는 완성돼 있지만, 종목 라운지 화면에서 이걸 호출하는 프론트가 아직 없다.
- **시세가 실시간이 아님**: 종목 가격은 실시간 API 연동이 아니라 DB에 시딩된 고정값이다(과거 시세 그래프는 `PriceWalk` 유틸로 현재가 기준 역산한 가짜 랜덤워크). 매매를 해도 가격이 움직이지 않는다.
- **국내(KRX) 종목 차트/검색 미지원**: TradingView 무료 위젯 라이선스가 국내 종목을 지원하지 않아, 종목 라운지의 차트·검색은 해외 종목만 대상으로 한다.
- **인증이 Spring Security로 완전히 전환되지 않음**: 로그인/관리자 체크가 아직 `LoginInterceptor`/`AdminInterceptor`(서블릿 인터셉터) 방식이고, `SecurityConfig`는 `anyRequest().permitAll()`로 전 요청을 허용만 하는 상태다.
- **이메일 인증이 실제 발송되지 않음**: 회원가입/비밀번호 재설정의 이메일 인증은 외부 메일 발송 없이 개발용 6자리 코드를 발급하는 방식으로만 구현돼 있다.
- **설정(`/setting`) 페이지 미구현**: 컨트롤러만 빈 채로 존재.
- **DB 비밀번호 평문 노출**: `application.properties`의 `spring.datasource.password` 기본값이 코드에 평문으로 남아있다. 환경변수로 덮어쓸 수는 있으나 기본값 자체를 git에서 제거하는 건 별도 정리가 필요하다.
- **최초 관리자 계정 수동 생성 필요**: 위 "테스트 계정" 참고 — 앱 안에서 스스로를 ADMIN으로 승격할 방법이 없다.
- **공유 DB로 인한 일시적 스키마 드리프트 가능성**: 여러 명이 같은 DB에 각자 다른 시점의 마이그레이션을 적용하면서, "컬럼이 없다"는 에러가 코드 문제가 아니라 SQL 적용 순서 문제로 발생한 사례가 있었다.

## 페이지별 기능 상세

### 홈 (`/`)

- 커뮤니티 전체 게시판 최신 글 6개(이미지 포함)
- 투자 수익률 랭킹 상위 5명 미리보기
- 용어사전에서 무작위로 뽑은 3개 용어 카드(새로고침마다 바뀜)
- 랭킹/용어사전 조회가 실패해도 게시글 영역은 그대로 뜨도록 예외 처리됨

### 커뮤니티 (`/community`)

게시판. 카테고리는 4개: **자유** / **종목토론** / **정보공유** / **반성일지**.

- 목록/상세/글쓰기/수정/삭제, 이미지 업로드 첨부
- 댓글 작성·수정·삭제 (대댓글 없이 1단)
- 게시글 좋아요, 댓글 좋아요 (각각 별도 컨트롤러)
- 게시글 북마크 (마이페이지에서 모아보기)
- 무한스크롤/피드용 `/community/feed` 별도 엔드포인트
- 작성자 닉네임 클릭 시 프로필 모달 팝업

### 종목 라운지 (`/trade-hub`, 구 "거래 허브")

종목 하나를 골라 차트를 보고 실시간으로 소통하는 화면. **서버는 시세 데이터를 직접 조회하지 않는다** — TradingView Advanced Chart 임베드 위젯이 클라이언트에서 자체 데이터로 그린다(국내 종목은 무료 위젯이 지원하지 않아 대상에서 제외, 해외 종목만).

- **차트**: TradingView 위젯. 헤더의 빠른전환 버튼 5종목(AAPL/MSFT/NVDA/TSLA/GOOGL) + 해외 종목 검색 자동완성(디바운스 3초)으로 종목 전환
- **종목별 실시간 채팅**: WebSocket(STOMP, `/ws-chat`)으로 종목 코드별 채팅방(`/topic/chat/{code}`) 운영. 도배 방지(5초 내 5회 이상 전송 시 30초 잠금, 100ms 미만 연속 전송 즉시 차단)를 서버가 최종 판단. 채팅은 30일 지나면 자동 삭제(매일 새벽 4시 배치)
- **"살까?팔까?" 실시간 투표**: 종목별 상승/하락 의견 투표(REST, 5초 폴링으로 갱신). 이미 투표한 항목을 다시 누르면 취소(토글). 매일 오전 10시에 전 종목 투표 자동 초기화(서버가 그 시각에 꺼져있었다면 재기동 시 놓친 초기화를 따라잡음)

## 랭킹 (`/ranking`)

- 회원 투자 수익률/수익금 기준 랭킹보드. 1~3위는 금·은·동 프로필 프레임으로 강조
- 비공개로 설정한 회원은 노출되지 않음
- 클릭 시 회원 프로필 모달로 상세 확인 가능

### 용어사전 (`/dictionary`)

- 카테고리 6개: 매매와 투자 행동 · 투자자·자금·손익 관리 · 상품과 포지션 · 시장·지수·주문·거래 제도 · 종목 정보와 기업 분석 · 차트와 기술적 분석
- 카테고리별 목록, 검색, 자동완성
- 다크 모드 지원

### 회원 (`/member/*`)

- 회원가입, 로그인/로그아웃, 아이디·닉네임 중복확인
- 이메일 인증: 실제 메일 발송 없이 개발용 6자리 코드를 발급하는 방식(회원가입/비밀번호 재설정 공용)
- 비밀번호 찾기·재설정, 마이페이지 비밀번호 재확인 후 정보 수정, 프로필 이미지 변경/삭제
- 회원 탈퇴
- 다른 회원 팔로우/언팔로우 (팔로워·팔로잉 목록은 "내 정보"에서 확인)

### 내 정보 (`/member/stocks`)

헤더 프로필 메뉴의 "내 정보". 프로필과 회원 활동을 한 화면에서 확인:

- 내가 쓴 글 / 내가 쓴 댓글 / 북마크한 글
- 팔로워 / 팔로잉 목록
- 내가 남긴 문의 내역

### 내 금융거래 (`/member/dashboard`)

헤더 프로필 메뉴의 "내 금융거래". 원래는 "내 주식"(보유 주식만) 화면이었다가, **여러 가상 증권사에 흩어진 자산을 한 화면에서 보여주는 통합 대시보드**로 확장됨:

- 보유 주식 + 금융상품(펀드/채권/ELS) 평가금액과 손익
- 계좌 연동(기존 가상 계좌 불러오기) / 신규 계좌 개설
- 입출금·매매·상품 거래 내역 타임라인(최근 항목 페이지네이션)
- 실현손익 조회
- 투자 목표 설정·취소, 목표 달성 이력 조회

### 가상 증권사 API (`/api/*`, `brokerage` 패키지)

화면은 없고 API로만 존재하는 모의투자 백엔드. 실제 증권사가 아닌 "이 사이트 안에서만 존재하는 가상 증권사" 여러 곳(수수료율이 서로 다름)을 시뮬레이션한다.

- 가상 증권사 목록·수수료 조회
- 주식/금융상품 상품 목록 조회 (주식은 모든 증권사 공통 취급)
- 계좌 개설, 기존 계좌 연동
- 매수/매도 체결 → 잔고·보유수량·평단가·거래이력 동시 갱신
- 제휴 증권사가 데이터를 내려준다고 가정한 형태(`partner` 서브패키지)로 시드 데이터를 흉내냄

### 관리자 페이지 (`/admin`)

- 회원 상태(정지 등)·권한 변경
- 게시글/댓글 공개여부 변경, 삭제
- 문의 답변 등록·완료 처리·삭제
- 용어사전 항목 추가·수정·삭제

### 설정 (`/setting`)

아직 미구현 (빈 컨트롤러만 존재).

## 공통 UI

- **헤더**: 홈 / 커뮤니티 / 종목 라운지 / 랭킹 / 용어사전 메뉴 + 다크모드 토글 + 로그인 시 프로필 드롭다운(관리자는 관리자 페이지로, 일반 회원은 내 정보·내 금융거래로)
- **프로필 모달**: 커뮤니티·랭킹에서 닉네임을 클릭하면 뜨는 공용 팝업(클릭 시점에 API로 데이터를 채움)
- **다크 모드**: 헤더 토글로 전환, 새로고침해도 유지(localStorage)

## 팀 협업 규칙

ㅇ 화요일·금요일 대면 회의에는 늦지 않도록 하며, 부득이한 지각·불참 시 사전에 팀원에게 카카오톡으로 공지한다.

ㅇ 모든 코드는 개인 브랜치에서 작업 후 Pull Request와 팀원 리뷰를 거쳐 main 브랜치에 병합하며, 직접 push를 금지한다.

ㅇ 하루 최소 1번은 main을 자기 브랜치로 pull하여 충돌 문제를 최소화한다.

ㅇ 모든 작업은 Trello 카드로 등록한 뒤 진행하고, 완료 시 즉시 카드 상태를 갱신한다.

ㅇ 프로젝트 진행 중간에 새롭게 떠오른 아이디어나 원하는 수정 사항이 있으면 카카오톡에 글로 남겨 모든 팀원이 볼 수 있게 한다.

ㅇ 1시간 이상 해결되지 않는 문제가 있을 시 팀원에게 공유하여 브레인스토밍으로 해결한다.

ㅇ 불가피한 사정으로 작업이 어렵거나 늦어질 경우 팀원에게 이를 알려야 한다.

ㅇ 코드 작성시 반드시 주석을 단다. 자신이 이해한 의도, 생각 등 작성하고, 최소한 코드의 20% 비율을 지킨다.

ㅇ 의견 충돌 시 다수결이 아닌 근거에 기반한 토론을 우선하고, 합의된 결정은 팀 전체가 따른다.
