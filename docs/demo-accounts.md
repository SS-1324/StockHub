# 데모용 미연동 계좌 (계좌 연동 테스트용)

`com.kh.demo.tools.DemoDataGenerator`가 만든, 아직 아무 회원과도 연동되지 않은 계좌 9개입니다.
회원가입 후 마이페이지에서 **계좌 연동**(`POST /api/accounts/link`)에 아래 정보를 입력하면,
이미 1년치 거래 이력이 쌓여있는 계좌를 그대로 가져올 수 있습니다.

| 증권사 | 예금주명 | 계좌번호 |
|---|---|---|
| 스톡증권 | 오지훈 | 110-222-000001 |
| 스톡증권 | 한소희 | 110-222-000002 |
| 스톡증권 | 배준영 | 110-222-000003 |
| 허브증권 | 임다은 | 102683300000001 |
| 허브증권 | 조성민 | 102683300000002 |
| 허브증권 | 황수아 | 102683300000003 |
| KH투자증권 | 문가영 | 789456120001 |
| KH투자증권 | 서준호 | 789456120002 |
| KH투자증권 | 나은채 | 789456120003 |

한 계좌가 한 회원에게 연동되면 재사용할 수 없습니다(`account_link.account_id`가 UNIQUE).
다시 테스트하려면 `com.kh.demo.tools.DemoDataGenerator`를 재실행해 이력을 다시 채우거나,
`account_link`에서 해당 계좌의 연동 행을 직접 지우면 됩니다.
